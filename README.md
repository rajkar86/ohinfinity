# Oh Infinity app pages

Public privacy policy and support pages for Oh Infinity apps, served by GitHub Pages from `main`, folder `/`.

- Spelling Bee Unlimited: `spelling-bee/privacy/` and `spelling-bee/support/`
- A new app adds a folder with the same two pages and a card on `index.html`.

Keep each privacy page true: if an app adds analytics, ads, accounts or network calls, update its page and its store privacy labels before that release.
